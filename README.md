# infinitereliefstudio-eng.github.io

Racine du domaine GitHub Pages d'Infinite Relief Studio.

- `index.html` redirige vers [BP Trainer](https://infinitereliefstudio-eng.github.io/BP-Trainer/), publié par le dépôt BP-Trainer.
- `.well-known/assetlinks.json` relie l'APK Android de BP Trainer à ce domaine, pour qu'elle s'ouvre sans barre d'adresse.
- `.nojekyll` fait publier le dossier `.well-known` (GitHub ignore sinon les dossiers qui commencent par un point).
